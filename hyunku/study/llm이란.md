# LLM (Large Language Model)

## 정의
**대규모 언어모델(Large Language Model)**을 의미합니다.

## 구현 방식
- **트랜스포머(Transformer) 모델**로 구현됩니다.

## 대표적인 모델들

### OpenAI 계열
- **GPT 시리즈**: GPT-3, GPT-4 등
- ChatGPT, GPT-4o 등

### Anthropic
- **Claude** 시리즈

### 기타 주요 모델
- Google의 Bard (Gemini)
- Meta의 LLaMA
- 국내 모델들 (HyperCLOVA X 등)

## 주요 강점

### 언어 처리
- **자연어 이해**: 텍스트 이해 및 생성에 특화
- **언어 번역**: 다국어 번역 및 변환
- **텍스트 요약**: 긴 문서의 핵심 내용 추출

### 예측 처리
- **패턴 인식**: 언어적 패턴을 통한 예측
- **문맥 이해**: 앞뒤 문맥을 고려한 추론

## 한계점

### 데이터 처리의 제약
- **수치 데이터 처리**: 효율적으로 개발된 것이 아님
- **정확한 계산**: 복잡한 수학적 연산에 제한
- **실시간 데이터**: 학습 시점 이후 데이터 인식 불가

### 환각 현상
- **사실 왜곡**: 학습하지 않은 정보에 대한 그럴듯한 거짓 정보 생성
- **수치 오류**: 정확한 계산이 필요한 상황에서의 오차 발생

## 시계열 데이터와의 관계
- 기본적으로 언어 처리에 최적화
- 수치 데이터 처리에는 한계 존재
- **Time-LLM** 등의 새로운 접근법 등장으로 한계 극복 시도
