# RAG (Retrieval-Augmented Generation)

## 정의
**검색 증강 생성(Retrieval-Augmented Generation)**의 약자로, 외부 지식 베이스를 활용하여 LLM의 응답을 개선하는 기술입니다.

## 주요 구현 도구

### LangChain
- RAG 파이프라인 구축을 위한 대표적인 프레임워크
- 다양한 데이터 소스와 벡터 데이터베이스 연동 지원

## 핵심 개념
- **데이터베이스 압축**: 많은 데이터베이스를 압축시켜놓은 모델
- **벡터화**: 텍스트 데이터를 수치 벡터로 변환
- **유사도 검색**: 질문과 관련된 정보를 빠르게 검색

## 작동 원리

### 인덱싱 단계
1. **문서 분할**: 큰 문서를 작은 청크로 분할
2. **임베딩**: 각 청크를 벡터로 변환
3. **저장**: 벡터 데이터베이스에 저장

### 검색 단계
1. **질문 벡터화**: 사용자 질문을 벡터로 변환
2. **유사도 검색**: 관련성 높은 문서 청크 검색
3. **컨텍스트 구성**: 검색된 정보를 LLM 프롬프트에 포함

### 생성 단계
1. **프롬프트 구성**: 질문 + 검색된 컨텍스트
2. **LLM 추론**: 증강된 정보를 바탕으로 답변 생성
3. **응답 출력**: 최종 답변 제공

## 기술적 장점
- **최신 정보 활용**: 학습 데이터 이후의 정보도 활용 가능
- **환각 감소**: 실제 문서 기반 답변으로 정확성 향상
- **도메인 특화**: 특정 분야 지식 강화 가능
- **확장성**: 새로운 문서 추가를 통한 지식 확장

## Time-LLM과의 연계
- 시계열 데이터 분석에 필요한 배경 지식 제공
- 과거 패턴 정보를 컨텍스트로 활용
- 도메인별 시계열 분석 방법론 검색 및 적용
- 유사한 시계열 패턴의 과거 사례 참조
