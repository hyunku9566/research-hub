# 시계열 데이터 (Time Series Data)

## 정의
**시계열 데이터**란 일정한 시간 간격을 두고 측정한 데이터를 말합니다.

## 주요 활용 분야

### 금융권
- 주식 가격 예측
- 환율 변동 분석
- 리스크 관리

### 과학 분야
- 기후 데이터 분석
- 실험 결과 모니터링
- 센서 데이터 처리

## 일반적인 목표
- **예측 모델 개발**: 일정한 해가 나오지 않는 수치에 대한 예측 모델을 개발하는 것이 보통의 목표
- **패턴 인식**: 시간에 따른 데이터 변화 패턴 파악
- **이상 탐지**: 정상 범위를 벗어난 데이터 포인트 식별

## 특성
- **시간 의존성**: 과거 데이터가 미래 예측에 중요한 영향
- **계절성**: 주기적 패턴 존재 가능
- **트렌드**: 장기적 증가 또는 감소 경향
- **노이즈**: 예측을 어렵게 하는 무작위 변동

## 분석 방법론

### 전통적 접근법
- ARIMA (AutoRegressive Integrated Moving Average)
- 지수 평활법 (Exponential Smoothing)
- 회귀 분석 기반 모델

### 머신러닝 접근법
- LSTM (Long Short-Term Memory)
- GRU (Gated Recurrent Unit)
- CNN-LSTM 하이브리드 모델

### 최신 접근법
- Transformer 기반 모델
- Time-LLM과 같은 언어모델 기반 접근법
